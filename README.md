# Lab 8 : Afficher et styliser des images dans une application React Native

## Objectif

L'objectif de ce TP est d'apprendre à importer et afficher une image locale dans une application React Native en utilisant le composant Image, et à personnaliser l'interface avec StyleSheet.

## Réalisation

Création du dossier imag et ajout du fichier logo.png.

Création du composant WelcomeScreen pour afficher l'écran d'accueil.

Importation du logo avec require("./imag/logo.png").

Utilisation de resizeMode="contain" pour afficher le logo sans le couper.

Utilisation de StyleSheet pour personnaliser les couleurs, les dimensions et les espacements.

Intégration de WelcomeScreen dans App.js.

## Résultat obtenu

L'application affiche :

Un bandeau orange (#EE9972).

Un logo de restaurant accompagné du titre AppName.

Un message : Welcome to our Mediterranean Bistro.

Un arrière-plan gris clair (#EDEFEE).
